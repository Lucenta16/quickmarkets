# QuickMarkets Installation Guide

## Windows Installation

### Option 1: Using the Installer (Recommended)
1. Download the `QuickMarkets-Setup-1.0.0.exe` file from the GitHub release
2. Run the installer and follow the on-screen instructions
3. Choose your installation directory when prompted
4. Complete the installation process
5. Launch QuickMarkets from your desktop shortcut or start menu

### Option 2: Portable Version
1. Download the `QuickMarkets-1.0.0-win.zip` file from the GitHub release
2. Extract the ZIP file to a location of your choice
3. Run `QuickMarkets.exe` to start the application

## Running in Screensaver Mode

To run QuickMarkets in screensaver mode:

1. Right-click on the QuickMarkets desktop shortcut
2. Select "Properties"
3. In the "Target" field, add `--screensaver` at the end of the path
   - Example: `"C:\Program Files\QuickMarkets\QuickMarkets.exe" --screensaver`
4. Click "Apply" and "OK"
5. Double-click the shortcut to run in screensaver mode

## Troubleshooting

If you encounter any issues:

1. Make sure you have an active internet connection for real-time data
2. Check that no firewall is blocking the application
3. Try running the application as administrator
4. If problems persist, please report them on our GitHub issues page

# QuickMarkets Windows Screensaver Installation Guide

## Installation Instructions

1. Download the `QuickMarkets-Screensaver.zip` file from the GitHub release
2. Extract the ZIP file to a temporary location
3. Right-click on `QuickMarkets.scr` and select "Copy"
4. Navigate to `C:\Windows\System32\` and paste the file
   - You may need administrator privileges for this step
   - On 64-bit systems, you might also need to copy to `C:\Windows\SysWOW64\`
5. Right-click on your desktop and select "Personalize"
6. Go to "Lock screen" and then click "Screen saver settings"
7. Select "QuickMarkets" from the dropdown menu
8. Click "Settings" to configure your watchlist and other options
9. Click "OK" to save your settings
10. Click "Preview" to test the screensaver

## Windows Screensaver Settings

The QuickMarkets screensaver integrates with the standard Windows screensaver settings dialog, where you can:

- Add/remove financial instruments to your watchlist
- Configure refresh rates for real-time data
- Set grid layout options
- Choose color themes

## Troubleshooting

If you encounter any issues:

1. Make sure you have an active internet connection for real-time data
2. Verify that the screensaver file was copied to the correct location
3. Try running the screensaver as administrator
4. Check Windows Event Viewer for any error messages
5. If problems persist, please report them on our GitHub issues page
